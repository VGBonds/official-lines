Issues

Each compared event's propositions are filed under an issue by an AI model, so that stances taken in different events on the same question can be read in one table over time. The model only chooses the issue; the stances, quotes and the wording of every proposition stay as the comparison recorded them. An issue is a grouping of differently worded propositions, so read the wording on each row before the stances. Method.
