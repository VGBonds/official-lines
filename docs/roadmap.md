# Roadmap and business plan

## Now (v1)

Collect ≈15 countries and ≈15 organisations in English, group by event, compare, publish a static site and a weekly brief. Run for a few weeks, read the output critically, tune the prompts and the sources.

## Next, in rough order

1. **Editor commands.** `parallax merge`, `parallax move` and `parallax split` for fixing event grouping without SQL.
2. **Better baseline for "unusual".** Today "unusual agreement" compares against Parallax's own history, which starts empty. Seed it with **UN General Assembly voting data** (the Voeten/Bailey dataset, public), which records how closely every pair of countries has voted for decades.
3. **Batch API for analysis.** Anthropic's batch API halves the price; analysis isn't urgent, so the daily comparisons could run as one batch.
4. **Second-model audit.** Re-run a sample of comparisons with a model from another vendor and publish where they disagree. It is an honest answer to "isn't your AI biased?".
5. **Central bank view.** Central banks are collected but off the map. A separate page could compare monetary-policy language over time (inflation, currency, sanctions): the most valuable piece for the finance audience.
6. **More languages.** Collect native-language versions alongside the English ones and compare the two: what does a government say at home vs abroad?
7. **More coverage.** Each new source should improve balance (Global South, regional organisations) more than volume.
8. **Legal check before a big launch.** Our display rule (title, link, own summary, quotes of at most ~30 words) is conservative, but get a media lawyer's opinion once there is an audience or revenue. Also check hosting-location questions if we ever add state media.

## Business plan

Goal: cover costs first, then see whether there is more. Order of effort:

1. **Weekly newsletter on Substack (start now).** Free tier for reach, later a paid tier (~$5–8/month) with the full brief and the archive. This builds the audience, which is the real bottleneck.
2. **Data for professionals.** Political-risk analysts, macro investors, journalists and think tanks pay for clean, structured history: statements, stance tables, and an **alignment index** between countries over time; for finance, central bank and finance ministry language. This only works with history, so the archive should start growing now. Channels: direct sales, alternative-data marketplaces.
3. **Licences for universities and newsrooms**, for research and teaching.
4. **Grants: careful.** Funding from government-linked bodies (NED, EU programmes and the like) would damage credibility for a project about government messaging. Private foundations are acceptable if disclosed.
5. **No advertising.** It conflicts with a neutral brand.

Name and domain: "Parallax" is the working name. Check domain and trademark availability before launch (e.g. parallax-lines.org, officiallines.org).
